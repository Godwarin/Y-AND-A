# Участие в разработке

Обычные ошибки и предложения оформляйте через Issues. Для уязвимостей используйте закрытый канал из [SECURITY.md](SECURITY.md).

Перед изменением кода прочитайте [архитектуру](docs/ARCHITECTURE.md) и [инструкцию сборки](docs/BUILD_FROM_SOURCE.md). Для предложения исправления создайте Fork, отдельную ветку и Pull request с описанием поведения и выполненных проверок. Указывайте фактический результат; синтетический поток не заменяет физический тест телефона.

Сохраняйте согласие MediaProjection на каждый сеанс, TLS certificate pinning, явное подтверждение AirPlay, лимиты сети/декодера и завершение дочерних процессов. Ключи, реальные QR, личные кадры, SDK и готовые бинарники в изменения не включаются. Новые зависимости должны иметь проверяемый upstream, закреплённую версию и сведения о лицензии.

Код проекта распространяется под GPL-3.0-only; сторонние условия перечислены в THIRD_PARTY_NOTICES.md. Изменённые GPL-компоненты сохраняются с полными исходниками. Свои Android-сборки подписывайте собственным ключом.
