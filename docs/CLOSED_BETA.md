# Проверка BETA-0.42

Для Windows распакуйте ZIP целиком и запустите Y AND A.exe. На Android установите APK из того же выпуска. На iPhone используется системный AirPlay. Пошаговое подключение описано в USER_GUIDE.md.

Владелец проверил подключение, изображение и звук на OPPO Reno5 Lite с Android 13 и iPhone 17 с iOS 27. Для поворота, остановки и отказа на каждом телефоне отдельный результат пока не записан.

В состав загрузок входят Windows ZIP, APK, архив исходников и зависимостей, подписанный манифест, открытый ключ и контрольные суммы. BETA-0.42 содержит проверенные исполняемые файлы версии 0.4.0-rc.1. Отдельная подпись манифеста позволяет проверить целостность файлов. У Windows EXE пока нет Authenticode.

Владелец выбрал закрытый репозиторий Godwarin/Y-AND-A. Перед первой загрузкой разработчик проверяет состав исходников и фактическую видимость репозитория. Команда `python scripts/verify-github-source.py` проверяет чистую копию проекта. Команда `./scripts/check-release-readiness.ps1 -Scope BinaryReleaseCandidate` отдельно сверяет подписанные загрузки и свидетельства испытаний приложения. Публичный выпуск требует отдельного решения владельца.
