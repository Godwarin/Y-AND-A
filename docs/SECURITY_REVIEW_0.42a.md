# Независимый аудит безопасности Y AND A 0.42a

Независимый статический аудит проверил исходники, инструкции установки и зависимости. Найдены четыре замечания средней важности и одно низкой. Последующие изменения скриптов сборки проверялись отдельно.

| Замечание | Состояние |
|---|---|
| Подмена локального кэша инструментов сборки | Проверка Android-инструментов и артефактов Windows добавлена. Требуется реальный отчёт доверенной чистой сборки для нового комплекта. |
| Удержание видеоканала AirPlay клиентом с тем же видимым IP | Для беты принято ограничение доверенной локальной сети. Возможна задержка законного сеанса при совпадении адреса. |
| Повторные запросы подтверждения AirPlay | Для беты принято то же ограничение. Сетевой клиент может мешать подключению повторными заявками. |
| Вмешательство в управляющее соединение AirPlay | Активный сетевой посредник может прервать уже разрешённый сеанс. Используйте доверенную сеть. |
| Направление к старому выпуску | Инструкция обновлена, проверка подписи теперь требует ожидаемую версию. |

Для 0.42a пройдена статическая проверка готовых файлов. Запуск на чистой Windows и изолированные сетевые проверки остаются неподтверждёнными. [Результаты](TEST_RESULTS.md) · [Политика безопасности](../SECURITY.md).
