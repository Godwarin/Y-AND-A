Тестовый комплект 0.42a находится в release/0.42a. BETA-0.42 остаётся замороженным комплектом до исправлений. Исторические файлы сохранены локально в archive/releases и не входят в чистый GitHub snapshot. BETA label не требует пересборки успешно проверенных бинарников. Источником label/product соответствия служит config/release.json. Внутренний номер APK и его publisher certificate сохраняются для совместимого обновления.

Репозиторий Godwarin/Y-AND-A пока private. Изменение visibility и окончательное публичное security approval не выполнялись.

Исходники прежней версии загружены в закрытый main. Для первого выпуска подготовить новый комплект с [исправлениями](SECURITY_REMEDIATION_2026-11-05.md), выбрать новую метку и повторить проверки. Старый локальный план BETA-0.42 сохранён как история.
