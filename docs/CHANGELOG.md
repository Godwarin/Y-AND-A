# Изменения

## Отдельный Telegram-бот «Мопс» от 2026-11-26

- Добавлен запуск с локальной Qwen2.5 7B, фильтрацией двух Telegram-аккаунтов и выбором группы. Токен вводится в скрытом поле, подпись добавляется программно.
- После патча первое обычное сообщение разрешённого участника привязывает группу. Мопс выбирает ворчание, прожарку или хоррор по реплике и номеру сообщения.
- Оператор может отправлять сообщения от имени мопса через приглашение `Мопс>` в консоли. Автоматические ответы продолжают обрабатываться параллельно.

## 0.42c — исправление для Windows

- Esc выходит из полного экрана на уровне окна Windows, включая сеанс AirPlay.
- В панели iPhone появилась подсказка о подключении Bluetooth-мыши к телефону через AssistiveTouch.

## 0.42b — сборка для проверки

- Полноэкранный режим отдаёт весь монитор трансляции. Панели возвращаются по Esc. Поворот телефона сохраняет полноэкранный режим.
- Мышь Windows выполняет нажатие, длинное нажатие и свайп на Android после отдельного согласия на телефоне. Управление доступно в обычном, компактном и полноэкранном окне.
- В тестовом архиве лежит тот же подписанный APK, который доступен отдельным файлом.

## 0.42a

- На Android получение параметров подключения ограничено встроенным сканером и ручным вводом.
- В AirPlay ограничены запросы до согласия, проверяется режим FairPlay и освобождаются заменённые сетевые ресурсы.
- Сборка Android проверяет хеши SDK и ZXing. Проверка подписи релиза требует ожидаемую версию. Подпись нового выпуска требует отчёта доверенной сборки Windows.
- Обновлены инструкции установки, результаты проверок и ограничения безопасности.
