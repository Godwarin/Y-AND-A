# Изменения

## 0.42a

- На Android получение параметров подключения ограничено встроенным сканером и ручным вводом.
- В AirPlay ограничены запросы до согласия, проверяется режим FairPlay и освобождаются заменённые сетевые ресурсы.
- Сборка Android проверяет хеши SDK и ZXing. Проверка подписи релиза требует ожидаемую версию. Подпись нового выпуска требует отчёта доверенной сборки Windows.
- Обновлены инструкции установки, результаты проверок и ограничения безопасности.
