# Y AND A 0.42a — проверка на телефонах

Распакуйте доверенный Windows ZIP целиком. На Windows 11 откройте `Y AND A.exe` без прав администратора. Убедитесь, что окно открывается и закрывается. Для трансляции подключите телефон по [инструкции](USER_GUIDE.md), проверьте изображение, звук обычного ролика и остановку. Сетевые испытания учитываются отдельно. [Результаты](TEST_RESULTS.md).
