# Результаты проверок Y AND A

## 0.42c

- Независимый прогон готового Windows EXE прошёл 26 проверок. Проверены полный экран, возврат по Esc с запущенным AirPlay-приёмником, нативный вывод Android и работа мыши с синтетическим Android-отправителем. Сетевой тест AirPlay использовал синтетический отправитель.
- В одном раннем прогоне Esc не вывел окно из полного экрана. При повторной проверке после подтверждения фокуса Windows прошли все шесть попыток, включая три с отключённой обработкой клавиши в WebView2. Причину первого таймаута установить не удалось.
- Пакет сверили с папкой запуска по SHA-256. При подготовке открытой беты обновлены инструкция, README и контрольные суммы внутри ZIP. EXE, приёмники, DLL и Android APK совпадают с проверенным комплектом.
- Владелец подтвердил выход по Esc из полного экрана во время живой трансляции с iPhone на 0.42c. Работа мыши на физическом Android и сопряжение Bluetooth-мыши с iPhone отдельно не подтверждены.

| Область 0.42a | Результат |
