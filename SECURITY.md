# Безопасность Y AND A

BETA-0.42 — предварительная версия. Не заявляется независимый пентест, сертификация или отсутствие неизвестных уязвимостей. Точный статус, hashes и ограничения: docs/SECURITY_RELEASE_REVIEW.md и TEST_RESULTS.md.

Не публикуйте действующие QR, signing keys, backup, пароли или личные кадры. Для обычной ошибки достаточно модели/ОС телефона, версии приложения, шагов и текста ошибки. Для потенциальной уязвимости планируется GitHub Private vulnerability reporting: Security → Advisories → Report a vulnerability. При открытии Public, до анонса выпуска, владелец должен включить этот закрытый приём сообщений в настройках репозитория. На этапе подготовки репозиторий закрыт, включение функции не заявляется. Если кнопки нет, не размещайте детали уязвимости в публичном Issue; сначала попросите автора предоставить закрытый канал. Обычные ошибки можно сообщать через Issues.

Проект не должен отключать защиту Windows, автоматически менять Firewall или обходить согласие MediaProjection/защиту контента. Для security validation применяются только собственные фикстуры в изолированном стенде, без реальных аккаунтов и телефонных данных. Неподтверждённые результаты остаются NEEDS_VALIDATION.

Ключи сборки хранятся только у владельца; исходники позволяют собрать unsigned Android APK и подписать свою модификацию самостоятельно. Это не обновит APK автора без соответствующего publisher key.
