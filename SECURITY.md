# Безопасность Y AND A

0.42a — предварительная версия. Статус проверок и известные ограничения описаны в документации. [Аудит 0.42a](docs/SECURITY_REVIEW_0.42a.md) · [Результаты](docs/TEST_RESULTS.md).

Не публикуйте действующие QR, ключи подписи, резервные копии, пароли или личные кадры. Для обычной ошибки достаточно модели и ОС телефона, версии приложения, шагов и текста ошибки. Для потенциальной уязвимости используйте закрытую форму GitHub, если доступна кнопка «Report a vulnerability» на вкладке Security. Если её нет, сначала запросите у владельца закрытый канал связи. Для обычных ошибок используйте Issues.

Проект не должен отключать защиту Windows, автоматически менять Firewall или обходить согласие MediaProjection/защиту контента. Для security validation применяются только собственные фикстуры в изолированном стенде, без реальных аккаунтов и телефонных данных. Неподтверждённые результаты остаются NEEDS_VALIDATION.

Ключи сборки хранятся только у владельца; исходники позволяют собрать unsigned Android APK и подписать свою модификацию самостоятельно. Это не обновит APK автора без соответствующего publisher key.
